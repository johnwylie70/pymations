# 3D

3D scenes are written the way Manim writes them: a `ThreeDScene`, 3D objects, and a camera you point with angles.

```python
from manim import *

class Shapes3D(ThreeDScene):
    def construct(self):
        axes = ThreeDAxes(x_range=[-3, 3, 1], y_range=[-3, 3, 1], z_range=[-2, 2, 1])
        self.set_camera_orientation(phi=70 * DEGREES, theta=-45 * DEGREES)
        title = Text("Three shapes", font_size=36).to_corner(UL)
        self.add_fixed_in_frame_mobjects(title)
        cube = Cube(side_length=1.5, fill_color=BLUE).shift(LEFT * 2.5)
        ball = Sphere(radius=0.9, resolution=(16, 16)).set_color(RED)
        cone = Cone(base_radius=0.8, height=1.6).shift(RIGHT * 2.5).set_color(YELLOW)
        self.play(Create(axes), FadeIn(cube), FadeIn(ball), FadeIn(cone))
        self.begin_ambient_camera_rotation(rate=0.3)
        self.wait(4)
        self.stop_ambient_camera_rotation()
        self.move_camera(phi=45 * DEGREES, theta=30 * DEGREES, run_time=2)
        self.wait()
```

## The camera

| Call | What it does |
|---|---|
| `set_camera_orientation(phi=, theta=, gamma=, zoom=)` | Point the camera at once. `phi` is the angle down from straight above, `theta` the turn around the vertical axis |
| `move_camera(phi=, theta=, zoom=, run_time=, added_anims=[...])` | Move the camera as an animation, with other animations alongside |
| `begin_ambient_camera_rotation(rate=0.02)`, `stop_ambient_camera_rotation()` | Keep turning around the vertical axis, `rate` radians a second |
| `begin_3dillusion_camera_rotation(rate=1)` | A small wobble that makes the scene look solid |
| `set_to_default_angled_camera_orientation()` | Manim's usual angled view |
| `add_fixed_in_frame_mobjects(title)` | Keep titles and labels flat on the screen, not turned by the camera |
| `add_fixed_orientation_mobjects(label)` | Place a label in 3D but keep it facing the camera |

Dragging the scrubber moves the camera too, so any moment can be seen exactly.

## 3D objects

| Object | What it is |
|---|---|
| `ThreeDAxes(x_range, y_range, z_range)` | Three axes; `axes.c2p(x, y, z)` and `axes.plot(...)` work as in 2D |
| `Surface(lambda u, v: [x, y, z], u_range, v_range, resolution)` | A surface from a function, checkered by default (`checkerboard_colors`) |
| `Sphere(radius)`, `Cube(side_length)`, `Prism(dimensions)`, `Cylinder(radius, height)`, `Cone(base_radius, height)`, `Torus(major_radius, minor_radius)` | Solids |
| `Tetrahedron()`, `Octahedron()`, `Icosahedron()`, `Dodecahedron()`, `Polyhedron(vertex_coords, faces_list)` | Polyhedra with flat faces |
| `Dot3D(point)`, `Line3D(start, end)`, `Arrow3D(start, end)` | Points, lines and arrows in space |

Every 2D shape works in 3D too: it lies flat in the plane `z = 0` until you move or turn it (`rotate(PI / 2, axis=RIGHT)`). Objects move, scale, turn and animate the same way as in 2D, with `OUT` and `IN` as the third direction.

## How it is drawn

Pymations draws 3D itself, on the same 2D canvas as everything else: each face is projected through the camera, shaded by one light (the same direction as Manim's), and drawn back to front by its centre. No WebGL is needed, so 3D works wherever the 2D scenes do. Like any back-to-front drawing, faces that cut through each other can be drawn in the wrong order where they cross; giving such surfaces a little more `resolution` makes it smaller.
